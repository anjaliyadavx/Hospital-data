# 🏥 Hospital Data Analysis

## 📌 Project Overview
This project analyzes hospital data to understand patient information,
health-related patterns, and important trends in the dataset.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## 📊 Analysis Performed
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Patient data analysis
- Category-wise analysis
- Data visualization
- Identification of important trends and patterns

## 📁 Files in this Repository

| File | Description |
|------|-------------|
| `hospital_data.csv` | Original hospital dataset |
| `hospital_data_analysis.ipynb` | Python analysis performed in Google Colab |
| `README.md` | Project documentation |

## 🎯 Project Objective
The main objective of this project is to analyze hospital data using
Python and extract meaningful insights through data analysis and visualization.

## 📌 Key Skills Demonstrated
- Data Cleaning
- Data Analysis
- Exploratory Data Analysis
- Data Visualization
- Python Programming
- Pandas & NumPy
