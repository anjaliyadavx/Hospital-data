# 🏥 Hospital Patient Analytics

## 📌 Project Overview

This project focuses on analyzing hospital patient data to understand patient demographics, medical conditions, admission patterns, test results, medication usage, insurance providers, hospitals, and billing information.

The project includes data analysis using Python and an interactive dashboard created in Power BI.

## 🎯 Project Objectives

- Analyze total number of patients
- Understand patient demographics and gender distribution
- Analyze different medical conditions
- Study patient admission types
- Analyze monthly admission trends
- Compare insurance providers
- Analyze medication usage
- Understand patient test results
- Identify top hospitals by patient count
- Analyze hospital billing amounts

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- Microsoft Power BI
- Excel / CSV

## 📊 Project Workflow

1. Collected and loaded the hospital dataset.
2. Cleaned and prepared the data using Python.
3. Handled missing and inconsistent values.
4. Standardized dates and categorical values.
5. Converted billing amounts into numeric format.
6. Performed exploratory data analysis.
7. Created visualizations using Python.
8. Built an interactive Power BI dashboard.

## 📈 Power BI Dashboard

The dashboard contains:

### Page 1 — Hospital Patient Analytics
- Total Patients
- Average Age
- Total Billing Amount
- Average Billing Amount
- Patients by Medical Condition
- Patient by Gender
- Patient by Admission Type
- Patients by Insurance Provider
- Monthly Patient Admissions
- Interactive slicers for Gender, Medical Condition, Admission Type, and Admission Year

### Page 2 — Hospital Details & Analysis
- Patients by Medication
- Patient Test Results
- Patients by Insurance Provider
- Top 10 Hospitals by Patients
- Synchronized filters for interactive analysis
